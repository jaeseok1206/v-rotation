# V-Rotation

배구 직관용 실시간 로테이션 트래커 (V-리그 남자부, 갤럭시 세로 화면 기준 PWA).

## 로컬 실행
```
python3 -m http.server 8000
```
PC 브라우저: http://localhost:8000 (개발자도구 → 모바일 에뮬레이션)

## 폰에 설치 (권장: GitHub Pages)
서비스워커/오프라인/전체화면 설치는 HTTPS에서만 동작합니다.
1. 이 폴더를 GitHub 저장소에 올리고 Settings → Pages 에서 배포
2. 갤럭시 Chrome/삼성인터넷에서 주소 접속 → 메뉴 → "홈 화면에 추가"

## 선수 명단 갱신
```
python3 scripts/fetch_players.py   # KOVO API → data/players.json
```
갱신 후 `sw.js`의 `CACHE` 버전을 올려 배포하면 폰에도 반영됩니다.

## 사용법
- 새 경기: HOME/AWAY 팀, 첫 서브 선택
- 라인업: 코트 자리 탭 → 오른쪽 명단에서 선수 탭 (다음 빈 자리로 자동 이동). 자리 두 곳 연속 탭 = 자리 교환. ⟲/⟳ = 한 칸 회전
- 리베로: 팀 이름 옆 `L 지정` 탭 → 명단에서 선택. 경기 중 후위 MB 자리에 자동으로 표시 (MB가 서브할 때는 MB 표시)
- 득점: 서브권 없는 팀이 득점하면 자동 로테이션 + 서브권 이동. 25점(5세트 15점) 2점 차에 세트 종료 확인
- 교체: 코트 선수 탭 → 명단 선수 탭 (또는 반대 순서)
- ↶ 되돌리기: 모든 동작을 한 단계씩 취소. 상태는 자동 저장되어 새로고침해도 유지
- 메뉴 → 코트 위/아래 바꾸기: 관중석에서 보이는 방향에 맞춤
